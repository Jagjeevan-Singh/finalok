# Desktop AI requirement: follow these steps yourself

**Why:** The brief explicitly asks you to work in a local project folder using **Codex, Claude desktop, or Antigravity desktop** and show **original AI conversation evidence**. A ChatGPT-created folder alone does not satisfy that requirement.

## Setup

1. Download and unzip `FinalOK_Jagjeevan_Assignment.zip` on your computer. Keep the folder local.
2. Open **one** of the three permitted desktop AI tools, using a legitimately available/free account if required. Do not pay for access.
3. Open or grant access to the extracted `FinalOK_Jagjeevan_Assignment` project folder using that tool's supported folder/project workflow. Do not claim it read the folder unless it actually did.
4. Keep `README_START_HERE.md`, `prototype/index.html` and the two PDFs visible in the folder.
5. **Ask the AI to inspect and critique, not blindly rebuild.** Save the original conversation as a screenshot/export. Make at least one identifiable change that you understand and can show on screen.

## Suggested genuine conversation prompts

**Prompt A: understand the work**

> Review the files in this local project folder. Do not pretend we interviewed any customers. The hiring assignment is capped at 4-5 hours. Explain the customer problem, existing alternatives, weak assumptions and one practical change you recommend. Keep the project simple enough for a person with about one year of experience to present.

**Prompt B: request a small actual edit**

> Inspect prototype/index.html. Please improve ONE usability detail in the client review step, for example clarifying what a version approval means or making the revision-comment requirement clearer. Keep it one offline HTML file. Do not add a database, paid service, WhatsApp API or a deployed backend. Show exactly what code changed and why.

**Prompt C: challenge the tool based on what it actually said**

> Which of your suggestions would increase scope without helping us test willingness to pay? Compare it with my constraint to keep the MVP focused on one clear approval decision. I want to reject any unnecessary features and document my reasons. Please revise your advice accordingly.

**Prompt D: ask for a verification**

> Give me five manual tests for create-review, approve, request-changes, reset, and mock lead capture. Identify anything that is simulated rather than live. Do not state that a test passed unless we actually ran it.

**IMPORTANT:** If the AI makes a weak suggestion, challenge that **actual suggestion in the original conversation**. If it does not, ask a critical follow-up grounded in its actual response. The example challenge below is only a category, **not a quote from an AI conversation**:

> “I do not want WhatsApp API automation or AI-generated summaries in the first version. They add complexity before we know users will pay. Keep sharing manual and ask the client for an explicit decision instead.”

Save the *real* AI messages and response, and the final change you approved. Never invent a conversation or create screenshots that look like authentic tool conversations.

## Evidence capture

- Save a screenshot/export showing the selected **desktop tool's name/UI**, the user's actual prompt and the AI's actual response.

- Show a changed file or test you actually performed after that interaction.

If the permitted tool cannot access the folder because of OS/access limits, state which tool/version failed and what you tried, and submit what you could complete. Do **not** purchase access.
